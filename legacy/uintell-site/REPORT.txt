United Intelligence Project Report
Updated: 2026-03-12

Current State
United Intelligence is a Rust-based website deployed for uintell.org and www.uintell.org.
The live site is intentionally minimal: a black page with the generated logo and the text "United Intelligence" under it.

What Is Running
1. Cloudflare DNS and Cloudflare Tunnel accept public traffic.
2. Nginx proxies uintell.org and www.uintell.org to 127.0.0.1:3001.
3. The Rust application serves:
   - /
   - /healthz
   - /logo.svg
   - /runtime-logo.svg
4. The united-intelligence systemd service starts the Rust app at boot.

What Was Removed
1. The SearXNG container was removed.
2. The SearXNG clone and runtime files were removed from this project.
3. Old static page assets were removed.
4. Reverse-proxy application code for SearXNG was removed.
