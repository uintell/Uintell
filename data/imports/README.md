# Import Paths

This directory is a placeholder only.

Large mutable corpora should live outside the repo by default, typically under:

- `/data/uintell/imports/wikipedia`
- `/data/uintell/imports/archwiki`
- `/data/uintell/imports/books`
- `/data/uintell/imports/notes`

Use source profiles to point Uintell at those external paths.

Do not keep large dumps, extracted archives, or generated import state in the repo root.
