# Knowledge Operating Model

This workspace is organized around a single principle: source material should stay inspectable.

## Reader behavior

- Open the clean reader first.
- Use backlinks to move laterally through the graph.
- Keep notes attached to documents when an interpretation matters.

## Search behavior

Hybrid search is the default because exact matching alone misses adjacent language and semantic search alone can drift.

## AI behavior

The assistant should only answer from retrieved evidence.
If the supporting passages are weak, it should say so plainly instead of filling gaps with confident guesses.
