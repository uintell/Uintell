# Better Than Google For Imported Knowledge

Google is good at finding public pages across the open web.
Uintell should be better at understanding, navigating, and interrogating trusted knowledge that the user already chose to import.

## What Google Is Good At

- finding a likely page somewhere on the public internet
- handling broad, ambiguous queries
- surfacing recent public discussions or vendor docs quickly

## What Uintell Should Be Better At

- finding the right page inside the user’s imported corpus without web noise
- showing why a result matched and where to jump inside the page
- helping the user understand the current page with citations and visible evidence
- keeping reading, search, answers, and related navigation in one calm workspace
- grounding answers in known sources instead of mixing in unknown web content

## User Moments That Must Feel Better Than Google

### Find the exact page I need

The user should see the right page or section quickly, with source labels, section labels, and obvious reasons for the match.

### Understand this concept quickly

The article page should be a better reading environment than a random docs tab from search results. Good typography, TOC, anchors, code rendering, and source context matter here.

### Trust the answer because I can inspect evidence

Ask-page answers should stay page-scoped first, cite claims, and make it obvious which passages support the answer.

### Discover what to read next

Backlinks, related pages, and source browsing should help the user continue learning without leaving Uintell or starting a new web search.

### Search inside my actual sources, not the noisy web

Search should respect the user’s imported corpus. Uintell wins by being narrower, cleaner, and more inspectable than the open web.

## What Uintell Should Not Try To Do Right Now

- general web search
- crawling the public internet
- broad “AI platform” behavior
- social or collaborative knowledge features
- graph visualization or exploratory novelty UI
- infrastructure expansion that does not strengthen import, search, reading, or cited answers

## Product Standard For This Sprint

If a user can search imported knowledge, open the best page, understand it faster than they would through web search, ask a narrow question, inspect the evidence immediately, and continue to related pages without leaving Uintell, this sprint succeeds.
